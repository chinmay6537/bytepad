    Self-hosted Piston server

    Cloud languages use Wandbox by default. To keep code on your own machines, enter the URL of a Piston server you run. The server must allow requests from this page (CORS).

    Give your program an input and the output you expect. Bytepad runs every case and shows the first line that differs. Trailing spaces and blank lines at the end are ignored.

    Available for Python. Click the margin beside a line number to set a breakpoint, then press Debug. Input typed in the Terminal tab still reaches your program.
